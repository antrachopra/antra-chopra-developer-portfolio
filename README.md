# Antra Chopra — Developer Portfolio

A responsive personal portfolio for Antra Chopra, a second-year Computer Science Engineering student at Dayananda Sagar College of Engineering in Bengaluru, India. It introduces her interests, technical skills, education, and project work.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Semantic HTML sections for Home, About, Technical Skills, Projects, Education, and Contact
- Skills grouped by area, without proficiency ratings
- Project cards with descriptions and technology tags
- CSS illustrations created for the portfolio projects
- Accessible skip link, clear navigation labels, keyboard focus styles, and reduced-motion support

## Projects featured

- **CampusConnect** — A campus application combining student services such as grades, course enrollment, events, fee information, and data handling with a mobile prototype focused on campus events and student engagement.
- **Text Tools** — A Django web application concept bringing together document processing, summarization, translation, and user authentication.

## Technologies

This portfolio website is built with **HTML5** and **CSS3**, using CSS Grid, Flexbox, CSS custom properties, responsive media queries, and Google Fonts. The technologies shown in the portfolio’s skills and project sections describe Antra’s learning areas and project stacks.

## Run locally

1. Open the `landing-page` folder in Visual Studio Code.
2. If you have the Live Server extension, open `index.html` and select **Go Live** in the status bar.
3. Your browser will open the local website. Save changes to HTML or CSS to see them in the preview.

You can also open `index.html` directly in a browser, though Live Server is more convenient while editing.

## Screenshots

Capture screenshots after checking the page at desktop and mobile widths. On Windows, open the page in Chrome, use **Win + Shift + S** to open Snipping Tool, and select the page area to capture. Save the images in `screenshots/` with these names:

- `screenshots/homepage.png` — the top of the portfolio
- `screenshots/projects.png` — the CampusConnect and Text Tools cards
- `screenshots/mobile.png` — the page at a narrow mobile width

After capturing, add the images here with Markdown, for example:

```md
![Portfolio homepage](screenshots/homepage.png)
```
